# Scoop bucket for YT Grabber

```
scoop bucket add progliodario https://github.com/progliodario/scoop-bucket
scoop install yt-grabber
```

Installs [YT Grabber](https://github.com/progliodario/YT-Grabber) for Windows. Start it from the Start menu
(*YT Grabber*) or run `YT-Grabber.exe` from `~\scoop\apps\yt-grabber\current`. Update with `scoop update yt-grabber`.

Scoop unpacks the installer instead of running it, so there is no entry in *Settings → Apps*: remove it with
`scoop uninstall yt-grabber`. Your settings and downloads list live in `%LOCALAPPDATA%\YT-Grabber` and are kept.
